WarmMemory architecture

An interactive walkthrough of how a query flows through a LangGraph agent using WarmStore as a capacity-bounded warm tier in front of a vector store. Click a strategy below to switch which retrieval path is active, then Simulate query to watch a request flow through it.

warm-fallback

Warm memory queried first. If the best score clears warm_hit_threshold, the vector store is never touched. On a miss, fall through to the durable tier. All writes are mirrored to both stores.

Code

store = WarmStore(capacity=16)
vector = InMemoryStore(index={"embed": emb, "dims": 1536, "fields": ["text"]})

hits = store.search(("alice",), query=q, limit=5)
if hits and (hits[0].score or 0) >= 0.34:
    chosen = hits                     # warm hit
else:
    chosen = vector.search(("alice",), query=q, limit=5)  # fallback
